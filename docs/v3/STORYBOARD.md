# Alarm nobody can sleep through — V3 (300 frames, 30 FPS)

No captions, subtitles, logos or on-screen text. Clock faces use ticks only. All visuals, materials and audio are generated locally through code. Uses the existing workshop, cast, ink pass, lens and Remotion project.

Camera motion is deterministic and purposeful on every shot; hard cuts occur at 60,150,195,225,255. Shake is a bounded event effect, not the base camera motion. All pose and object state is a pure function of the absolute frame so out-of-order rendering is safe. No physics simulation or wall-clock animation.

## Replaceable narration guide (no robotic voice is used)

- 0.0–2.0: “An alarm nobody can sleep through.”
- 2.0–4.0: “Just one little test…”
- 4.0–6.5: [Let the bell cascade tell the story.]
- 6.5–8.5: “Perhaps it works…”
- 8.5–10.0: “…a little too well.”

The video is delivered with synthesized sound effects, not narration. No suitable voice generator is available in this session. The timing guide can be recorded/replaced without changing picture timing.
